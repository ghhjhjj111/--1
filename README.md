# 仓库物资出库入库商品信息审核库存查询统计图表条码扫描管理系统

源码获取：ym7k.com/19766/

## ✅ 核心模块

### 1. 商品信息管理 + 审核模块

- 商品档案录入：名称、分类、规格、单位、成本售价、供应商、库位、批次、保质期、条码
- 商品新增后**提交审核**，审核员通过 / 驳回，未审核商品不能做出入库
- 支持 Excel 批量导入商品、条码标签打印（一维码 / 二维码）
- 商品信息修改、停用、归档、检索筛选

### 2. 条码扫描模块（重点）

- 网页端摄像头扫码、USB 扫码枪、PDA 手持终端扫码识别
- 扫码自动带出商品信息，无需手动打字；出入库、盘点、移库都支持扫码校验
- 条码重复校验、非法条码拦截，扫码记录留痕，一物一码追溯

### 3. 入库管理（带审核流程）

- 入库单：采购入库、退货入库、调拨入库
- 制单员填单 / 扫码录明细 → 提交审核 → 审核通过后库存自动增加；驳回可修改重提
- 入库单据预览、打印、导出，记录入库人、审核人、时间

### 4. 出库管理（带审核流程）

- 出库单：领料出库、销售出库、调拨出库
- 拣货扫码复核，防止多发错发；单据提交审核，审核通过扣减库存
- 控制负库存开关，可设置不允许超库存出库

### 5. 库存查询 & 库存管理

- 实时库存查询：按商品、分类、仓库、库位、供应商多条件检索
- 库存明细、库存流水台账（每一笔出入库都有记录）
- 库存预警：低于安全库存自动标记提醒；呆滞物料提醒
- 盘点管理：扫码盘点、生成盘盈盘亏单、盘点单审核、库存调整

### 6. 统计图表可视化（ECharts）

- 首页数据看板：今日入库、今日出库、库存总数、待审核单据数量
- 图表类型：出入库趋势折线图、商品分类库存占比饼图、出入库排行柱状图、库存周转统计
- 各类报表：出入库明细表、库存汇总表、盘点差异表，支持导出 Excel/PDF

### 7. 系统权限管理（RBAC）

角色区分：录入员、审核员、仓库管理员、主管、查看员

- 录入员：只能制单、扫码，不能审核
- 审核员：审核商品档案、出入库单据
- 主管：查看全部图表报表、权限配置

### 8. 基础数据

仓库、库区库位、商品分类、供应商、客户、字典、日志记录

## 📌 业务流程闭环

商品建档 → 提交审核 → 审核通过生成条码标签 → 扫码入库（审核）→ 库存增加 → 扫码出库（审核）→ 库存扣减 → 库存流水记录 → 自动统计生成图表 → 库存预警 / 盘点
